# 🐤 Wing Dodge 3D

A 3D bird-flying arcade game built with [Three.js](https://threejs.org/).
Flap to fly, dodge obstacles closing in from all four sides, collect stars, and unlock new worlds.

**▶ Play:** https://newser-dev.github.io/wing-dodge-3d/

## Features
- 4 worlds: 🌲 Forest, 🏛️ Temple, 🪟 Glass, 🟨 Backrooms
- 5 birds with unique skills, buyable skins & cosmetics
- Star economy, revive system, leaderboard-ready
- 15 languages (English default, switch in Settings)
- Mobile touch controls + desktop keyboard

## Controls
- **Tap / Space** — flap (jump up)
- **◀ ▶ / arrow keys** — move left/right
- **✨ button / Shift·S** — bird skill

## Tech
Single self-contained `index.html` (no build step). Three.js is loaded from a CDN.
